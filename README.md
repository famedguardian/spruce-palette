# Spruce Palette — how to put this online for free

This folder is a complete, ready-to-go website. You don't need to write
any code — just follow the steps below. Total cost: $0.

## What you're doing, in plain terms

You're going to:
1. Put this folder on GitHub (a free place to store code online)
2. Connect it to Vercel (a free service that turns code into a live website)
3. Get a real link you can open on your phone or computer, and "install"
   like an app

## Step 1 — Create free accounts

- Go to **github.com** and sign up (free)
- Go to **vercel.com** and sign up using "Continue with GitHub" (free —
  this links the two accounts automatically)

## Step 2 — Upload this folder to GitHub

1. On github.com, click the **+** in the top right → **New repository**
2. Name it `spruce-palette` → click **Create repository**
3. On the next page, click **uploading an existing file**
4. Drag this entire folder's contents into the browser window (all the
   files and folders — `src`, `public`, `package.json`, etc.)
5. Click **Commit changes** at the bottom

## Step 3 — Deploy on Vercel

1. On vercel.com, click **Add New** → **Project**
2. Find `spruce-palette` in the list and click **Import**
3. Leave every setting as-is — Vercel will detect it automatically
4. Click **Deploy**
5. Wait about a minute. You'll get a link like
   `spruce-palette.vercel.app` — that's your live site

## Step 4 — Put it on your phone or desktop like an app

- **iPhone:** open the link in Safari → tap the Share icon → **Add to
  Home Screen**
- **Android:** open the link in Chrome → tap the ⋮ menu → **Add to Home
  Screen** (or **Install app**)
- **Desktop (Chrome/Edge):** open the link → click the install icon (a
  small monitor with a down arrow) in the address bar

It'll open full-screen with its own icon, just like a regular app — but
it costs nothing to host and there's no app store to deal with.

## Making changes later

Any time you want to change a color, add a leather, or tweak wording, come
back here and I'll update the file (`src/App.jsx`) — then you just
re-upload it to GitHub and Vercel updates the live site automatically
within a minute or two.
